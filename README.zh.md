## 🎯 工程原则 (Engineering Principles)

- 🧱 **不可变与声明式基础设施**: 运用 NixOS 与 GitOps 打造可重现且高可靠的环境。
- ⚡ **高吞吐与极低延迟**: 借助 Go 和现代异步运行时实现轻量快速的后端架构。
- 🛡️ **类型安全与高维护性**: 严格遵循静态类型检查与模块化工程标准。
- 📦 **容器优先**: 从本地开发到生产部署保持全流程环境一致性。
