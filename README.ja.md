### 💡 プロフィール (About Me)

はじめまして！堅牢なシステム設計とシンプルなエンジニアリングを追求する開発者 **KRCUPRO** です。

- 🔭 **注力分野**: 高並行バックエンド、分散システム、クラウドネイティブインフラの構築。
- ⚡ **開発環境**: **Go**、**TypeScript**、**Docker**、**NixOS** を中心に活用。
